C. Subsystem 3: Three-Tier Defense-in-Depth Safety Control Plane
Child safety is enforced deterministically across the three decoupled layers: (1) Pre-Retrieval Input Guardrail: Canonicalizes
text using NFKD Unicode normalization, strips invisible zero-width tracking characters, eliminates control characters, and
executes regex pattern matching against prompt extraction, instruction override, jailbreaks, delimiter injections, and profanity
lexicons. Any violation immediately aborts execution in under 2ms, returning an age-appropriate polite refusal without
invoking the retriever or LLM; (2) Instruction Hardening: Untrusted evidence is sealed within the unambiguous XML
boundaries (<evidence>...</evidence>) accompanied by strict system instructions forbidding prompt execution from
evidence blocks; and (3) Post-Generation Output Guardrail: Screens generated tokens for system prompt fragments,
delimiter echoes, and unsafe phrasing before transmission.
D. Subsystem 4: Privacy-Preserving On-Device Speech Pipeline
To support young learners with emerging typing skills, the application incorporates a local speech interface. Audio recorded
via the browser's MediaRecorder API (WebM/Opus) is transmitted to POST /api/audio/transcribe. The Node.js server spawns
an isolated Python worker executing OpenAI's open-source Whisper base model locally on CPU. Audio buffers are
processed in memory and purged immediately, guaranteeing complete compliance with COPPA without external cloud
telemetry.

The English-Only V1 benchmark contains 77 structured questions: 65 answerable questions accompanied by gold textbook

Mathematically, BM25 scoring for query q and document chunk d is expressed as:
 Score_BM25(q, d) = SUM_{t in q} IDF(t) * [ TF(t, d) * (k1 + 1) ] / [ TF(t, d) + k1 * (1 - b + b * (|d| / avgdl)) ]
where k1 = 1.5, b = 0.75, |d| is chunk word length, and avgdl is average chunk length across the corpus. For dense retrieval,
unit-normalized embeddings v_q and v_d yield an inner product that is strictly cosine-equivalent:
 Score_Dense(q, d) = < v_q, v_d > = cos( e(q), e(d) )
Reciprocal Rank Fusion merges candidate lists across M = {BM25, Dense}:
 RRF(d) = SUM_{m in M} 1 / [ k + r_m(d) ],    with k = 60
