IX. MULTIMODAL SPEECH PROCESSING AND ON-DEVICE PRIVACY
Young primary school learners often struggle with keyboard text entry. To permit natural speech interaction without
violating student privacy regulations, we architected an on-device speech pipeline. Audio recorded via the client browser's
MediaRecorder API (WebM/Opus) is sent to POST /api/audio/transcribe. A dedicated Node.js bridge creates an
isolated Python worker performing OpenAI's open-source Whisper base model locally on CPU. Raw audio buffers are
decoded into FP32 arrays wholly in memory and purged immediately following transcription. By avoiding commercial
third-party cloud transcription APIs, the system excludes child biometric voice leakage, guaranteeing compliance with
COPPA (16 CFR Part 312) [18] and FERPA [19]. Blended tutor audio is produced on the client via the browser's native
Web Speech API, needing zero network round-trip overhead.
